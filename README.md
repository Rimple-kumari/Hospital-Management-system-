# 🏥 Hospital Management System

The **Hospital Management System (HMS)** is a web-based application built with PHP and MySQL that streamlines the administrative and patient management processes in hospitals. This system enables hospital staff to manage appointments, patient records, doctor schedules, billing, and more through a clean and secure interface.

---

## 🚀 Features

- 👨‍⚕️ Admin dashboard to manage doctors, departments, and appointments
- 🧑‍🦱 Patient registration and record management
- 🗓️ Appointment booking and schedule tracking
- 💊 Prescription and medical history recording
- 💵 Billing and invoice generation
- 🔐 Secure login for admins, doctors, and patients
- 📊 Real-time statistics and reports
- 📱 Responsive design using HTML, CSS, and Bootstrap

---

## 🛠️ Tech Stack

| Technology | Description                 |
